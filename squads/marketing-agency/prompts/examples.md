# Marketing Agency Squad - Example Prompts

## 1. Full Campaign Build
```
/pro:squad marketing-agency Build a complete lead generation campaign for a B2B SaaS product.
Budget: $15,000/month. Channels: Google Ads, LinkedIn Ads, Email. Target: CTOs and VP Engineering
at companies with 50-500 employees. Need landing page, ad creatives, email sequence,
and analytics dashboard.
```

## 2. Analytics Dashboard
```
/pro:squad marketing-agency dash Design and build a marketing analytics dashboard that pulls data
from GA4, Meta Ads, and Google Ads. Need: channel performance comparison, funnel visualization,
budget pacing, A/B test tracker, and weekly automated report generation.
```

## 3. Social Media Content System
```
/pro:squad marketing-agency pixel Build a content management system for a social media agency
managing 20+ client accounts. Need: content calendar with approval workflow, asset library,
scheduling integration (Meta, LinkedIn, TikTok APIs), performance tracking, and client portal.
```

## 4. Brand Identity System
```
/pro:squad marketing-agency prism Create a complete brand identity system for a fintech startup.
Deliverables: logo concept specifications, color palette (light/dark mode), typography system,
iconography guidelines, social media templates, email template design, and a brand guidelines
document. Target audience: millennials and Gen Z.
```

## 5. Email Marketing Automation
```
/pro:squad marketing-agency pixel Build an email marketing automation platform with: subscriber
management, segmentation engine, drag-and-drop email builder (MJML), A/B testing for subject
lines and content, automated drip sequences, analytics dashboard, and integration with
Stripe for purchase-triggered emails.
```

## 6. Landing Page A/B Testing
```
/pro:squad marketing-agency Build a high-converting landing page for a product launch with
A/B testing capability. Need 3 variants testing: hero message, CTA placement, and
social proof format. Implement GA4 event tracking, Meta Pixel, and conversion tracking.
Target: 5% conversion rate from paid traffic.
```

## 7. Campaign Performance Review
```
/pro:squad marketing-agency dash Analyze our Q4 campaign performance across all channels.
We spent $45K total: $20K Google Ads, $15K Meta Ads, $5K LinkedIn, $5K email.
Generated 1,200 leads and 85 customers. Generate a comprehensive report with funnel
analysis, channel comparison, audience insights, and Q1 budget reallocation recommendations.
```

## 8. Content Calendar Strategy
```
/pro:squad marketing-agency campfire Create a 3-month content strategy and calendar for an
e-commerce fashion brand. Channels: Instagram (daily), TikTok (4x/week), Email (weekly),
Blog (2x/month). Include seasonal events, content pillars, posting schedule, and
approval workflow. Budget for content production: $8K/month.
```

## 9. Multi-Client Agency Platform
```
/pro:squad marketing-agency Build a white-label agency management platform. Features needed:
multi-client dashboard, content approval workflow, automated reporting (pull from GA4/Meta/Google Ads),
team task management, client-facing portal, and billing integration. Support 50+ clients.
```

## 10. Conversion Rate Optimization
```
/pro:squad marketing-agency dash Our e-commerce site has 100K monthly visitors but only 1.2%
conversion rate. Analyze our funnel (Homepage > Category > Product > Cart > Checkout > Purchase)
and design a CRO strategy. Need: heatmap analysis plan, A/B test roadmap (10 tests),
tracking implementation, and a CRO dashboard to monitor improvements.
```

# Marketing Agency Squad

Specialized squad for building marketing technology platforms, campaign management tools, analytics dashboards, and brand identity systems.

## Agents

| Agent | Name | Base | Specialty |
|-------|------|------|-----------|
| content-dev | Pixel | dev | Social media APIs, CMS, A/B testing, analytics integration |
| analytics-analyst | Dash | analyst | GA4, Meta Pixel, UTM tracking, conversion funnels, attribution |
| campaign-pm | Campfire | pm | Content calendars, campaign lifecycle, budget allocation |
| brand-ux | Prism | ux | Brand guidelines, color systems, typography, visual identity |

## Workflow

**Campaign Creation Cycle** (`workflows/campaign-cycle.md`)
Multi-phase workflow: Brief > Strategy > Content Creation > Launch > Analyze > Optimize

## Templates

- **Campaign PRD** — Campaign project requirements with KPIs and channel strategy
- **Content Calendar** — Multi-channel content calendar with scheduling metadata
- **Analytics Report** — Performance report template with channel breakdowns

## Usage

```
/pro:squad marketing-agency — Load the full marketing agency squad
/pro:squad marketing-agency pixel — Load only the content developer overlay
```

## Integrations Supported

- Google Analytics 4 (GA4) / Google Tag Manager
- Meta Business Suite (Facebook/Instagram Ads)
- TikTok Business API
- LinkedIn Marketing API
- Mailchimp / SendGrid / Brevo
- Stripe (for subscription/payment tracking)
- Headless CMS (Sanity, Strapi, Contentful)

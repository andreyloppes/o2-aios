# Content Calendar Template

## Overview
Multi-channel content calendar for organizing, scheduling, and tracking marketing content across all platforms.

### Content Pillars
| Pillar | % of Content | Description | Example Topics |
|--------|-------------|-------------|----------------|
| Educational | 30% | Teach something valuable | How-tos, tips, industry insights |

## Content Status Workflow

```
Draft > In Review > Client Approval > Approved > Scheduled > Published > Analyzed
```

| Status | Description | Owner |
|--------|-------------|-------|
| Draft | Content written, assets in production | Creator |
| In Review | Internal team review | Team Lead |
| Client Approval | Sent to client for approval | Client |
| Approved | Client approved, ready to schedule | Creator |
| Scheduled | Scheduled in platform/tool | Creator |
| Published | Live on platform | Automated |
| Analyzed | Performance data collected and reviewed | Analyst |

## Asset Checklist Per Post

- [ ] Copy written and proofread
- [ ] Visual asset created in correct dimensions
- [ ] Hashtags researched (Instagram: 5-15, LinkedIn: 3-5, TikTok: 3-5)
- [ ] UTM parameters set for any links
- [ ] CTA aligns with campaign objective
- [ ] Alt text written for images
- [ ] Content pillar tagged
- [ ] Scheduled at optimal time for the platform
- [ ] Client approval received (if required)

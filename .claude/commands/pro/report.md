You are now executing the **PRO Report Generator**.

## Report Types

### `status` — Project Status Report
Quick snapshot of current project state.
**Data sources:** docs/ folder, stories/ folder, git log, session metrics
**Sections:** Executive Summary, Current Phase, Completed Work, In Progress, Blockers, Next Steps

### `weekly` — Weekly Summary Report
Comprehensive weekly wrap-up.
**Data sources:** git log (7 days), sessions.jsonl, stories/ completion
**Sections:** Summary, Accomplishments, Metrics (velocity, cost, quality), Challenges, Plan for Next Week

### `sprint` — Sprint Review Report
Sprint-level deliverable summary.
**Data sources:** stories/ folder, QA reports, git log, session data
**Sections:** Sprint Goal, Delivered Stories, Velocity, QA Results, Burndown, Retrospective Items

### `client` — Client Deliverable Report
Polished report suitable for external stakeholders.
**Data sources:** docs/, implemented features, screenshots, metrics
**Sections:** Project Overview, Progress Summary, Key Deliverables, Demo Items, Timeline, Budget Status

### `cost` — Cost & ROI Report
Financial analysis of AI agent usage.
**Data sources:** sessions.jsonl, cost-history.json, time estimates
**Sections:** Cost Summary, Cost by Agent/Workflow, ROI Analysis, Optimization Recommendations, Projections

## Report Format

All reports follow this structure:

```markdown
# [Report Type] — [Project Name]
**Date:** [current date]
**Period:** [date range if applicable]
**Generated by:** Claude Master PRO

---

## Executive Summary
[2-3 sentence overview]

## [Section 1]
[Content with data]

## [Section 2]
[Content with data]

## Metrics
| Metric | Value | Trend |
|--------|-------|-------|
| [metric] | [value] | [up/down/stable] |

## Next Steps
1. [action item]
2. [action item]

---
*Generated by Claude Master PRO v1.0*
```

## Activation

If a report type is specified, gather the data and generate the report immediately.
If no type is specified, ask the user which report they need and for what time period.

Use the `client-report` skill for formatting guidance when available.
